# 商析 Dashboard

面向电商经营分析的 React + TypeScript 单页应用。当前支持 CSV 导入、字段确认、表关系诊断、指标计算、自适应分析页面和数据分析助手。

## 开发命令

```bash
npm install
npm run dev
npm test
npm run build
```

生产构建输出到 `dist/`。

## 目录

- `src/`：前端源码、指标引擎和测试。
- `demo-data/`：本地演示 CSV。
- `scripts/`：测试与浏览器验收脚本。
- `docs/current/`：仍然有效的项目说明。
- `docs/archive/`：历史计划、任务书和验收记录；默认开发不需要读取。

当前产品范围见 `docs/current/PROJECT_PLAN.md`。历史资料仅用于追溯，不代表当前实现。
