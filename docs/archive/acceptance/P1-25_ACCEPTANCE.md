# P1-25 验收记录

- 任务：建立单表类型识别器
- 实现日期：2026-07-26

## 已完成

- 增加独立的单表类型字段，不与文件角色混用。
- 支持用户行为单表、订单主表单表、订单明细单表、订单宽表和待选择五种状态。
- 用户行为表通过 behavior/action/type 等字段识别。
- 订单主表通过 order_id + order_amount 识别。
- 订单明细单表通过 order_id + product_id + price/amount 识别。
- 订单宽表通过同时存在订单字段和商品字段识别，并提示同一订单可能出现多行。
- 无法判断的表显示“待选择”，不会强制猜测。
- 字段确认页允许用户修改单表类型；类型与文件角色冲突时阻止确认。
- 旧会话缺少单表类型字段时自动重新识别。
