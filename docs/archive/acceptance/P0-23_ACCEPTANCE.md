# P0-23 验收记录

- 任务：处理重复角色文件
- 实现日期：2026-07-26

## 已完成

- 检测同一角色的多个文件，包括订单主表、商品表、用户表等。
- 未选择处理方式前，阻止确认字段映射。
- 提供四种明确选择：纵向合并、分别作为不同数据集、替换已有文件、取消处理。
- 兼容表头的同角色文件可真实纵向合并，行数和预览数据会合并，结果不依赖上传顺序。
- 表头不兼容时拒绝直接合并并提示先分别处理或统一字段。
- 替换操作会实际移除未保留文件，不再保留重复角色。
- 选择分别作为不同数据集后，当前单数据集页面会阻断确认，不会静默取第一张表。
- 旧会话缺少重复角色决策字段时自动兼容为空，避免恢复失败。

## 专项验收

- 两张订单主表会被检测为一个重复角色组。
- 兼容表头的订单主表可以纵向合并为一个逻辑文件。
- 表头不一致的重复角色文件不能直接合并。
- 分别作为不同数据集不会继续生成顺序依赖的单数据集指标。
