# 数据导入第一版任务清单

按顺序逐项推进，后续可直接说“继续做数据导入任务 01”。

## P0 基础链路

### 任务 01：建立导入会话状态
- 目标：上传文件、预览、字段映射和确认结果共享一个 `ImportSession`。
- 完成：进入字段确认再返回上传页，真实文件和状态不丢失。

### 任务 02：替换 CSV 解析逻辑
- 目标：支持引号、字段内逗号、空值和不同换行。
- 完成：带逗号商品名不会拆列，失败有明确错误。

### 任务 03：实现真实预览
- 目标：展示表头、前 5 行、行数、列数、分隔符、编码、警告和错误。

### 任务 04：完善状态和继续按钮
- 目标：支持 `queued/reading/ready/warning/error`；读取中或失败时不能继续，并提供重试/移除。

### 任务 05：字段确认接入真实文件
- 目标：移除固定 `orders.csv`、`products.csv` 等假文件，只显示用户上传文件。

### 任务 06：增加文件角色和字段映射
- 目标：支持行为表、订单主表、订单明细、商品、用户、退款、未知角色的推荐和手动修改。

### 任务 07：生成指标能力清单
- 目标：逐项显示 GMV、订单量、购买行为数、购买用户数、商品排行、渠道贡献、退款率、复购率和行为漏斗是否可用及原因。

## P1 首版交付

### 任务 08：用户行为单表模式
- 按 `behavior=buy` 计算 GMV、购买件数、购买用户数和购买行为数，展示 `pv -> fav -> cart -> buy` 漏斗；无 `order_id` 时不得写真实订单量。

### 任务 09：订单多表模式
- 检查 `order_id/product_id/user_id` 关系；订单指标按订单粒度、商品按明细粒度、退款按退款粒度，避免 GMV 重复。

### 任务 10：数据质量摘要
- 展示空值、重复行、坏日期、金额异常、外键匹配率和时间范围差异；错误阻止继续，警告说明影响。

### 任务 11：拖放上传和重复文件处理
- 支持拖放；使用独立文件 ID；同名文件可分别预览、删除和更新。

### 任务 12：示例模板下载
- 提供用户行为模板和订单多表模板，下载后可重新上传并正确识别。

### 任务 13：明确模拟数据边界
- 完成导入后明确显示仅完成结构确认；看板仍用模拟数据时必须标注。

### 任务 14：响应式、无障碍和构建验收
- 检查 1440px、768px、390px 三种宽度、键盘焦点和 `npm run build`。
